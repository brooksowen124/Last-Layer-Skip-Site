CubeClip Privacy Policy

Effective November 1, 2026

CubeClip is a local-first Chrome extension for saving short camera clips while practicing with csTimer.

Information CubeClip processes

  • Camera video after the user explicitly starts buffering and grants permission.
  • Microphone audio when the user enables audio and grants permission.
  • Recording preferences such as clip length, resolution, and microphone choice.
  • Visual theme colors read from csTimer solely to match its interface.

Use, storage, and retention

Camera and optional microphone data are encoded locally into a rolling memory buffer. Older footage is overwritten when the configured duration is reached. When the user selects Save clip, CubeClip writes the requested preceding footage to Downloads/CubeClip. Unsaved footage is discarded when buffering stops or the extension process ends.

Preferences and theme colors remain in Chrome's local extension storage until the user clears the data or uninstalls CubeClip. Saved clips remain until the user deletes them.

Data transmission and sharing

CubeClip does not upload camera footage, microphone audio, preferences, theme information, or saved clips. It has no servers, accounts, analytics, advertising, or telemetry. It does not sell or share user information.

Permissions

  • Camera and microphone: Create the user-requested rolling media buffer.
  • Downloads: Save a clip only after the user requests it.
  • Storage: Store preferences and locally sampled theme colors.
  • Offscreen: Continue buffering while the popup is closed.
  • cstimer.net: Add the Save Clip control and read theme colors. CubeClip does not read or store solve history.

User controls

Users can disable microphone capture, stop buffering, delete saved clips, clear extension data, revoke camera or microphone access in Chrome, or uninstall CubeClip.

Limited Use

CubeClip's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only for CubeClip's user-facing clipping and interface features.

Changes and contact

Material changes will be reflected here and in the Chrome Web Store listing before updated data practices take effect. Questions can be submitted through the CubeClip public support tracker.
